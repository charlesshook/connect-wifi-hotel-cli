# connect-wifi-hotel-cli

This project was created because I got annoyed with hotel captive portals when I wanted to connect my laptop to the hotel network.

## Features
- Connect to a wifi network
- Handles networks with captive portals

## Installation
### Compile from source
Install a recent version of [Go](https://go.dev/) <br>
Then to build:
```
go build main.go
```

### Insall with go get
Install a recent version of [Go](https://go.dev/) <br>
Then:
```
go get github.com/charlesshook/connect-wifi-hotel-cli@latest
